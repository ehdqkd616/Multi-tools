# 🧰 Multi-tools

> *A personal toolkit, built one utility at a time.*

---

## Overview

**Multi-tools** is a lightweight, ever-growing collection of everyday utilities — designed for one user, tailored to real life.  
No bloated features, no unnecessary sign-ups, no clutter.  
Just fast, focused tools that solve small but recurring problems.

---

## 💡 Why It Exists

Life is full of tiny calculations and repetitive tasks that don't deserve their own app.

- Figuring out take-home pay after taxes
- Splitting a bill evenly among friends
- Converting units
- Tracking small budgets

**Multi-tools** brings all of these together in one place, built exactly to fit how you actually work and live.

---

## 🧭 Core Philosophy

| Principle | Description |
|---|---|
| **Simple over comprehensive** | Each tool does one thing well |
| **Personal over generic** | Built for one person's actual needs, not a mass market |
| **Growing over finished** | New tools get added whenever a new "I wish I had a tool for this" moment comes up |
